Tutorials
=========

Hands-on walkthroughs that demonstrate common PyTheranostics workflows.

Most pages here are guided lessons: read them through, and run the cells if you
want to follow along. A few are task-oriented notebooks meant to be downloaded,
configured and executed against your own data — they say so at the top. For
those, keep patient data, credentials and generated outputs outside the
repository, and never commit executed cells containing patient information.
